# Libra — Library Management Dashboard (Frontend Only)

## Run
1. Extract `library_management_frontend.zip`.
2. Open the extracted folder.
3. Double-click `index.html` to open it in your browser.

No installation, backend, database, or internet connection is required (Google Fonts are optional; the page uses fallback fonts).

## Features
- Summary cards: total logins, total students, active sessions, and new students.
- Recent student login activity table.
- Refresh activity button that updates the sample login count.
- Add demo student button that updates the sample student totals.
- Responsive layout for desktop and mobile.

## Important
This is a frontend-only demonstration. Counts and student activity are sample data and are not connected to real authentication, a database, Prometheus, or Grafana. The buttons update values only in the current browser session.
